The ADK ships a set of skills that teach your AI coding assistant how to work with ADK primitives. Your assistant can scaffold files, add integrations, run evals, and debug issues with the right conventions, without extra setup from you.

<Info>
  Before you start, [install the ADK CLI](/adk/get-started/install). For the full init wizard walkthrough and project layout, see the [Quickstart](/adk/get-started/quickstart).
</Info>

## Start a project

```bash
adk init my-agent
cd my-agent
```

`adk init` installs ADK skills into the project automatically. Your AI coding assistant picks them up the next time you open the folder.

## Skills installed

| Skill | Use when |
|-------|----------|
| `botpress-adk` | Building features: actions, tools, workflows, conversations, tables, Zai |
| `botpress-adk-integrations` | Discovering, adding, and configuring integrations |
| `botpress-adk-evals` | Writing and running evals to test your agent |
| `botpress-adk-debugger` | Reading traces and logs, diagnosing failures |
| `botpress-adk-frontend` | Building a frontend app that calls your agent |
| `botpress-adk-docs` | Writing or updating docs inside your project |

Your assistant loads the right skill automatically when you ask for help with a matching task.

## Build with your assistant

Start the dev server so your assistant can run and test the agent:

```bash
adk dev
```

Prompt your assistant based on what you're trying to do. The right skill loads automatically.

**Add a feature**

```txt
Add a Notion integration and write a conversation that creates a page when a user shares a note.
```

Loads `botpress-adk-integrations` to find and add Notion, then `botpress-adk` to scaffold the conversation handler in `src/conversations/`.

**Debug an issue**

```txt
My agent replies with "I can't help with that" whenever a user asks about orders. Read the latest traces and figure out what's blocking it.
```

Loads `botpress-adk-debugger`, which runs `adk traces` and `adk logs`, walks the trace tree, classifies the failure, and proposes a fix.

**Write tests**

```txt
Write an eval for the onboarding conversation that checks the agent collects the user's name and email in the first three turns.
```

Loads `botpress-adk-evals` to draft an eval file with the right turn structure and assertions, then runs it against the dev server so you can see it pass or fail.

You review and edit every change before it lands.

## Claude Code slash commands

Claude Code layers slash commands on top of the skills. Install the plugin once:

```txt
/plugin marketplace add botpress/skills
/plugin install adk@botpress-skills
```

Then use:

| Command | What it does |
|---------|--------------|
| `/adk-init` | Scaffold a new ADK project |
| `/adk-debug` | Debug issues using traces, logs, and the debug loop |
| `/adk-eval` | Write, run, or debug evals |
| `/adk-integration` | Discover, add, and configure integrations |
| `/adk-frontend` | Build a frontend that integrates with your agent |
| `/adk-doc-create` | Create docs for a feature in your bot |
| `/adk-doc-review` | Review project docs for accuracy |
| `/adk-doc-update` | Update project docs after code changes |
| `/adk-doc-sync` | Check if project docs match your code |
| `/adk-doc-search` | Search your project docs |

Cursor and Codex use the installed skills automatically. No commands needed.

## Deploy

When the agent is ready, ship it:

```bash
adk deploy
```
