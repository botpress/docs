title: Install
description: Install the ADK CLI on macOS, Linux, or Windows.
---

The ADK CLI is the command-line tool you use to create, run, and deploy Botpress agents.

<Info>
  You'll need [Node.js](https://nodejs.org/) 22.0.0 or higher.
</Info>

Run the install command for your operating system:

<CodeGroup>

```bash macOS & Linux
curl -fsSL https://github.com/botpress/adk/releases/latest/download/install.sh | bash
```

```powershell Windows (PowerShell)
powershell -c "irm https://github.com/botpress/adk/releases/latest/download/install.ps1 | iex"
```

</CodeGroup>

If you'd rather use a package manager, install the CLI from npm instead:

```bash
npm install -g @botpress/adk-cli
```

Open a new terminal and verify the installation:

```bash
adk --version
```
