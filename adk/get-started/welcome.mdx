The Agent Development Kit (ADK) is a TypeScript framework for building AI agents on Botpress. You define conversations, workflows, tools, and tables as code in a lightweight project, and the ADK compiles them into a production agent that runs on the Botpress Cloud runtime.

A minimal agent is a single file:

```typescript src/conversations/index.ts
import { Conversation } from '@botpress/runtime'

export default new Conversation({
  channel: '*',
  handler: async ({ execute }) => {
    await execute({
      instructions: 'You are a helpful AI assistant built with Botpress ADK.',
    })
  },
})
```

Run `adk dev` and the ADK starts a local dev server, opens a Control Panel, and rebuilds your agent on every save. Run `adk deploy` to ship it to Botpress Cloud.

## What's in an agent

An ADK project has a small set of primitives. Each one lives in its own folder under `src/`, gets picked up automatically, and is strongly typed end-to-end.

<CardGroup cols={2}>
  <Card title="Conversations" horizontal icon="message-square" href="/adk/concepts/conversations">
    Handle messages from users across any channel.
  </Card>
  <Card title="Workflows" horizontal icon="route" href="/adk/concepts/workflows">
    Run long-lived, resumable logic with automatic state.
  </Card>
  <Card title="Actions" horizontal icon="bolt" href="/adk/concepts/actions">
    Expose callable functions to your agent and the platform.
  </Card>
  <Card title="Tools" horizontal icon="wrench" href="/adk/concepts/tools">
